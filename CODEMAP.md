# Карта кода ColorsAction

Сначала смотреть сюда, потом искать по коду. При изменении структуры (новые папки, системы, перенос файлов) — обновить карту.

## Сборки

| Сборка | Папка | Что внутри |
|---|---|---|
| `GameCore` (+`.Newtonsoft`) | `Packages/com.template.gamecore` | Шаблонное ядро без движка: DI, конфиги, события, FSM, тики, реактивный UI. Не трогать без нужды. |
| `GameCore.Unity` | `Packages/com.template.gamecore.unity` | Мост ядра к Unity: `GameHostBehaviour`, источники конфигов, логгер. |
| `ColorsAction.Game` | `Assets/Game/Logic` | Логика игры **без UnityEngine** (`noEngineReferences`). Тестируется `dotnet test dotnet/ColorsAction.sln`. |
| `ColorsAction.Unity` | `Assets/Game/Scripts` (кроме `Editor/`) | Всё, что живёт в сцене: игрок, бой, враги, уровень, UI. |
| `ColorsAction.Unity.Editor` | `Assets/Game/Scripts/Editor` | Сборщик сцены, плейтест, импорт моделей. |
| `ColorsAction.LevelEditor` | `Assets/Game/Scripts/Editor/LevelEditor` | Unity-редактор воксельных уровней. |

## Логика (`Assets/Game/Logic`)

- `ColorsActionInstaller.cs` — регистрация сервисов в DI. `LaunchOptions.cs` — параметры запуска (уровень, стартовое оружие с апгрейдом, опыт) и `LevelKeys` (ключ `VoxelLevels/…` — воксельная карта). `GameSession.cs` — состояние игры: инвентарь, выносливость, здоровье, опыт (он же «деньги» прокачки), открытые срезки, `CompletedHints`, `BrokenCrates` (разбитые ящики), `OpenedChests` (открытые сундуки), `OpenedBridges` (опущенные разводные мосты), `OpenedKeyDoors` (открытые двери на ключ), `DroppedKeys` (ключи, уже выпавшие из врагов), `LastBonfire`, `Upgrades`, схема управления; `GiveResources` (ресурсы в инвентарь, событие `ResourcesGained`); ключи — `PickUpKey(doorId)`, `HasKey`, `TryOpenKeyDoor` (ключ тратится).
- `Configs/` — классы JSON-конфигов: `Configs.cs` (Combat + `PoiseConfig` (Combat.json `poise`: сколько шкалы врага дают удар и парирование, спад); множители шкалы `ItemConfig.Poise`, `AttackStepConfig.Poise`, `PlungeConfig.Poise`, `ShieldConfig.BashPoise`; Game, Player + выносливость/здоровье (`PlayerHealthConfig`: максимум, прирост за уровень `MaxAt`, i-frames, мигание `BlinkHidden`)/деформация, Camera, Colors, Items + `AttackStepConfig` комбо с `fxFrom/fxTo`, `upgrade`, `hop`, `chargeable` (общий заряд оружия `ItemConfig.Charge`, `ChargeFor`), Combat, Inventory), `DodgeConfig.cs` (серия отскоков), `WeaponMoveConfigs.cs` (`ChargeConfig`, `FinisherConfig`, `PlungeConfig`), `UpgradeConfigs.cs` (Upgrades.json: цены апгрейдов — опыт + ресурс оружия `resource`/`resources`), `ChestConfig.cs` (Chests.json: вид сундука, открытие, полёт ресурса), `EnemyConfigs.cs` (тип врага: объём шкалы выносливости `poise`, `elite`, стойкость `hyperArmor`, `deflectDuration`; атака — движения `Sweep/Overhead/Slam/DiagonalRight/DiagonalLeft`, удар по области `areaRadius/areaOffset`, серия ударов `combo` (`Step`, `StrikeSpan`); радиуса агро тут нет — он у врага на карте `LevelEnemy.AggroRadius`/`LevelObject.AggroRadius`, по умолчанию `LevelEnemy.DefaultAggroRadius`; `movement` — профиль из Movement.json для проверки достижимости), `CrateConfig.cs` (Crates.json: HP ящиков, `breakableBy`, вид), `BridgeConfig.cs` (Bridges.json: прочность цепи, `breakableBy` — дробовик, вид, падение створки), `StatusEffectsConfig.cs` (StatusEffects.json, ключ `StatusEffectsConfig.Key`: эффекты по id — вид `kind`, длительность, сила `value`, складывание `stacking`, подсветка `tint`; `onParry` — что враг получает при парировании кроме оглушения), `LevelConfig.cs` (+ `bonfires`, `keyDoors` (`LevelKeyDoor`), ключ у врага `LevelEnemy.Key` = id двери, `crates`, `chests` (ресурс и количество), `bridges`, подсказки с `target`).
- `Combat/` — `DamageRules` (урон × множитель цвета, `HitResult.Effect` — слабый/сильный/антипод), `ColorWheel` (круг 6 цветов из Combat.json `colorWheel`, расстояние по кругу → `colorDistanceMultipliers`), `Health`/`PlayerVitals`, `Stamina` (+ `Refund` — удачное парирование выносливость не тратит), `Poise` (шкала выносливости врага: `Add` → заполнилась `Broken`, спад после паузы, `HitAmount` — вклад удара), `EnemyBrain` (решения врага; свой `AggroRadius`, `LoseRadius` не меньше него; `Tick(..., playerReachable)` — недостижимого игрока спокойный враг не замечает; `Poise`: `OnDamaged(poise)` и `Parry` копят шкалу, полная — ошеломление (`Staggering`), парирование без полной шкалы лишь поглощает удар (`ParryStunned` = false, `Parried` на `DeflectDuration`); серии ударов `RootAttack`/`ComboIndex`; стойкость `HyperArmor`), `CombatDirector` (очередь врагов на атаку), `LockOnRules` (+ `Nearest` — передача фокуса), `Shotgun` (`ShotParams` — параметры залпа, `ShotPattern`, `PelletVolley`, `GunTrigger`), `DodgeCombo` (серия отскоков), `AttackCharge` (общий заряд удержанием: вспышка на пике, окно и спад множителя), `ComboFinisher` + `ComboSteps` (отложенный добивающий, удары за апгрейдами), `PlungeAttack` (удар в прыжке без потери инерции, удар при приземлении), `BlockRules` (блок за выносливость: щит гасит весь удар, дробовик — долю `GunBlockConfig.Absorb`; пробитый блок), `ShieldBash` (удар щитом; щит меча — `ItemConfig.Offhand`, его ступени прокачки — у меча: `ShieldConfig.BashUpgrade` и др.), `BreakableState` (`Breakable.cs`: здоровье разрушаемого, ломается только оружием из списка).
- `Status/` — статус-эффекты для врага и игрока: `StatusEffects` (контроллер носителя: `Apply(id, duration)`, `Remove`, `Clear`, `Tick`, события, сумма влияния `Modifiers` — `IsStunned`, `DamageTakenMultiplier`, `DamageDealtMultiplier`), `StatusEffect` (база: время, стаки, хуки `OnApplied/OnTick/OnRemoved/Modify`; `StatusModifiers`, `IStatusTarget`), `StatusEffectKinds` (реестр видов `kind` → класс: `StunEffect`, `DamageTakenEffect`, `DamageDealtEffect`; новый вид — класс + `Register`), `HealthStatusTarget` (урон эффектов в `Health`). Враг: `EnemyBrain.Status` (оглушение → состояние `Stunned`; парирование — стан на `ParriedDuration` + `ApplyParryEffects` в момент удара о щит). Игрок: `GameSession.PlayerStatus` (тикает TickScheduler; уязвимость — в `PlayerVitals.TryHit`, оглушение — `PlayerController.HasControl`).
- `Inventory/` — `PlayerInventory` (рук нет: оружие — на колесе `Weapons`, в руках `Active`, смена `SetActive`, `WeaponOfColor`; в сетке оружие не лежит; сетка и быстрые слоты 1–4 — расходники и ресурсы; `Hand` — только сторона сокета модели; `Item.Charges` — заряды расходников; стопки ресурсов `Item.Count`/`ItemConfig.MaxStack`: `CountOf`, `TryAddCount`, `TryConsume`, слияние перетаскиванием; ключ — `ItemKind.Key`, `Item.KeyFor` = id двери, `FindKey`), `ItemDatabase`, `HealItems` (лечилка: использование, восполнение у костра; `GameSession.UseQuickItem`/`RefillConsumables`, событие `QuickItemUsed`).
- `Progression/` — `WeaponUpgrades` (уровни апгрейдов 0..3, `Has(itemId, tier)`; отладка `debugWeaponUpgrades` в Game.json), `WeaponUpgradeShop` (покупка за опыт + ресурс оружия из инвентаря, `Missing` — чего не хватает), `Bonfire` (события отдыха/респауна).
- `Level/` — воксельная модель (`VoxelLevel`, `VoxelLevelData`, `VoxelTypes`), `VoxelPlayLayout` (объекты воксельной карты → списки `LevelConfig` с высотой опоры `Y` для игры), `CrateStackShape` (стопка ящиков 2×1×N: клетки по yaw, объект `LevelObjectKind.CrateStack`), сундук — `LevelObjectKind.Chest` (`Item` — ресурс, `Count` — количество), `DrawBridgeShape` (разводной мост 4×2×2: клетки по yaw, стена поднятой створки, объект `LevelObjectKind.DrawBridge`), двери на ключ — `LevelObjectKind.KeyDoor`, ключ — у врага `LevelObject.Key`; `KeyDoorRules` (предупреждения расстановки для обоих редакторов, `Holders`, `AssignHolder`), правки и история (`LevelEditing`, `MarkupCommand.PutObjects` — несколько объектов одной отменой), `SurfaceSmoothing`, `ShortcutDoorRules`, `HintTargets` (подсказки гаснут после подбора/двери), `LevelEdgeWalls` (невидимые стены по краю карты и высота смерти от падения), `Navigation/` (граф и A* для врагов; `EnemyReach` — дойдёт ли враг до игрока: граф с настилом мостов, закрытые двери (срезки и на ключ)/ящики/поднятые мосты — стены, кэш до изменения мира).
- `States/States.cs` — FSM: Boot → Play ↔ Inventory / Bonfire. `UI/` — `InventoryScreenViewModel` (сетка + крестовина 1–4 `CrossLayout`, подпись оружия в руках `WeaponCaption`), `BonfireScreenViewModel`.

## Unity (`Assets/Game/Scripts`)

- `Core/` — `GameBootstrap` (точка входа сцены, хост ядра, создаёт HUD/инвентарь/EventSystem из префабов, регистрирует `LaunchOptions`), `LaunchOptionsStore` (UserSettings/ColorsActionLaunch.json), `GameInput` (действия клавиатура/геймпад по GDD: TAB/Y — колесо `GameAction.Wheel`, I/Select — инвентарь, F1 — схема камеры; `PreviewStick` — правый стик в интерфейсе), `Palette`, `ComponentPool` (пулинг), `GlowMaterials` (копии материалов с `_EMISSION` для белой вспышки неуязвимости), `GameTimeScale` (единственный владелец `Time.timeScale`: замедление колеса + фриз-кадры удара).
- `Player/` — `PlayerController` (ходьба, бег, прыжок, серия отскоков, хуки удара в прыжке), `BoxMotor` (кинематика бокса), `CubeDeformer` (деформация куба), `PlayerDamageReceiver` (урон, блок, i-frames с белым свечением тела и оружия, смерть/респаун, смерть при падении ниже `KillHeight`, урон от падения с высоты по ступеням `PlayerConfig.FallDamage`, быстрые слоты 1–4 — лечилка), `PlayerLockOn` (фиксация цели: враги, манекены, цепи мостов), `AimMarker`.
- `Combat/` — `PlayerCombat` (partial: `.cs` — атаки обеих рук, комбо, позы; `.Moves.cs` — заряд, добивающий, удар в прыжке, окно эффекта; `.Shotgun.cs` — выстрел пулями, заряд, блок на доп. атаке и выстрел после парирования (`GunParryShot`), позы дробовика; `.Shield.cs` — блок (щит и дробовик: `BlockAngle`, `BlockAbsorb`), парирование, удар щитом), `Pellet` (пуля из пула), `WeaponGlow`, `ParticleFx` (разовые эффекты на Particle System из `Resources/Fx` с пулом и окраской в цвет оружия: `ChargeFlash` — белая вспышка на пике заряда (не красится), `GroundSlam` — удар по земле, `HitFlash` — тёплая вспышка парирования, удара по цепи, дула, лечения: `ParticleFx.Flash`), `WeaponTrail` (след клинка: частицы префаба `Fx/SwordTrail` с чётким краем (`Art/Fx/TrailDot`) испускаются вдоль клинка, плюс яркая кромка по траектории острия), `StatusDamage` (урон игрока × усиление игрока × уязвимость цели `IStatusHolder` — во всех местах расчёта урона в `PlayerCombat*`), `StatusTint` (пульсирующая подсветка носителя цветом эффекта), `TrainingDummy`, `Hittable` (`IHittable`, `HitInfo` + `WeaponId`, `Poise` — вклад удара в шкалу врага, `IWeaponGate`/`HitGate` — цели, которые берёт не любое оружие). `ShotFx` больше не используется.
- `Enemies/` — `EnemyController` (радиус агро и `EnemyReach` приходят из `LevelBuilder` через `Spawn`; `KeyDoor` — ключ, который враг роняет, событие `Died`; движение, атаки, анимации, реакция на парирование, статус-эффекты `IStatusHolder` — подсветка, поза оглушения; удар по игроку ждёт конца окна парирования; удар по области — круг у точки удара и волна `GroundSlam`; движения `Slam`/косые «накрест»), `PoiseBar` (шкала выносливости над головой: world-space Canvas, тает вместе с оглушением), `EnemyFx` (трещины, осколки `DebrisChip` из пула, опыт, маркер тревоги).
- `Items/` — `Pickup` (предмет на земле, префаб `Resources/Items/Pickups/<Name>`; без модели — склянка из примитивов; ключ от двери — `InitKey(doorId)`, префаб `Pickups/Key`), `PickupVisual`, `ItemVisual` (цвет оружия + `SetBlink` — белая вспышка поверх), `Interactable`/`PlayerInteractor` (E / X).
- `Level/` — `LevelBuilder` (уровень из конфига: карта высот или воксельная карта через `VoxelLevelView`, спавн предметов/врагов/подсказок/дверей/костров, невидимые стены, `RespawnEnemies`), `Bonfire` (костёр), `Voxel/` (`VoxelLevelView`, `VoxelMesher`), `HintMarker` (подсказки на полу), `ShortcutDoor`, `KeyDoor` (дверь на ключ: открывается с любой стороны ключом из инвентаря, ключ поворачивается в замке, плита уходит в пол; ключ роняет враг — `LevelBuilder.DropKey`), `Chest` (сундук: E / X, деформация при открытии, ресурс кусочками `Debris` летит к игроку), `CrateStack` (стопка ломаемых ящиков из досок: урон только мечом через `IWeaponGate`, доски отлетают, при разрушении разваливается), `DrawBridge` (разводной мост по референсу: створки из досок на шарнирах у берегов, П-образные рамы, красные шестерни, падение дальней створки с отскоком) + `BridgeChain` (две цепи — одна цель пуль и фиксации, рвутся только дробовиком).
- `UI/` — `Hud`, `WeaponWheel` (колесо оружия: TAB/Y держать — замедление времени, сектор мышью/левым стиком геймпада (персонаж от стика не ходит, пока колесо открыто), отпустить — `Inventory.SetActive`; кулдаун и замедление — Combat.json `weaponWheel`; создаётся в `GameBootstrap`), `InventoryView` (крестовина 1–4 и сетка; старый префаб с портретом достраивает сам), `CharacterPreview` (3D-превью игрока с оружием: копия куба на слое 30 под миром, своя камера в RenderTexture, вращение правым стиком/мышью), `SlotView`, `HudItemSlot`, `ItemIcons` (id → спрайт), `BonfireView`/`BonfireCell` (меню костра), `UiFactory`, `UiSprites`. Префабы UI: `Assets/Game/Resources/UI` (Canvas + CanvasScaler 1920×1080), иконки: `Assets/Game/Art/UI/Icons` (ресурсы — Metal/Gears.png (Rivets.png не используется), генератор `Tools/Icons/make_resource_icons.py`). `SlotView` показывает число в стопке.
- `Camera/CameraRig.cs` — Cinemachine-камера. `Camera/CurvedWorld.cs` — искривление мира к горизонту (Camera.json → `curvedWorld`): глобальные параметры шейдеров только для игровой камеры (превью и окно сцены плоские), расширенная пирамида отсечения вверх, та же формула для кода экрана — `Bend` (цифры урона в `Hud`, «!» и шкала стойкости над врагом), `Raycast`/`RaycastPlane` (прицел мышью в `PlayerController`; невидимые стены края карты — метка `Level/EdgeWall` — луч курсора пропускает). Физика и логика плоские.
- `Editor/` — `LaunchOptionsWindow` (окно «Параметры запуска»: карта, стартовое оружие, опыт, кнопка «Играть»), `LevelImporter` (импорт карт веб-редактора .json/.json.txt в `Configs/VoxelLevels`, меню ColorsAction/Уровни), `PrototypeSceneBuilder` (собирает сцену/префабы из кода), `UiPrefabBuilder` (+ `EnsureKeyPrefabs`: модель `Resources/Items/Key` и `Pickups/Key`, меню ColorsAction/UI/Create Key Prefabs and Icon) и `BonfireMenuPrefabBuilder` (меню ColorsAction/UI), `FxPrefabBuilder` (меню ColorsAction/Build FX Prefabs: префабы `Resources/Fx`, текстуры и материалы `Art/Fx`, шейдер `ColorsAction/Particle`), `PrototypePlaytest` (автопрогон; итог пишет в `Logs/playtest_result.txt` через `PlaytestResultFile`), `PlaytestResultFile` (итог автопрогона в один файл `Logs/<имя>`, перезаписывается: первая строка `PASS|FAIL|RUNNING|ABORTED N/M — имя, время`, дальше только упавшие проверки с `expected`/`actual`), `CratePlaytest` (автопрогон ящиков на VoxelLevels/Test, итог — `Logs/crate_playtest_result.txt`), `BridgePlaytest` (автопрогон моста на VoxelLevels/BridgeTest, нужен дробовик, итог — `Logs/bridge_playtest_result.txt`), `PlayModeStepper`, `ModelImportSettings`, `LevelEditor/` (Unity-редактор уровней; у врага — поле «Радиус агро» и круг зоны на сцене, «Ключ от двери»; у двери на ключ — «Ключ у врага», пунктир к врагу; раздел «Проверка» с предупреждениями `KeyDoorRules`).

## Данные и ассеты

- Конфиги: `Assets/StreamingAssets/Configs/*.json` (Player, StatusEffects, Items (+ ресурсы kind `Resource`: metal, gears; виды предметов — Weapon/Shield/Consumable/Resource), Upgrades, Chests, Enemies, Combat, Camera, …), уровни — `Configs/VoxelLevels` (`BridgeTest` — коридор с мостом над пропастью для автопрогона), `Configs/Levels`.
- Префабы: `Assets/Game/Resources/Items` (оружие в руках), `Resources/Items/Pickups` (на земле), `Resources/UI`, `Resources/Fx` (эффекты на Particle System), `Assets/Game/Prefabs`. Сцена: `Assets/Game/Scenes/Prototype.unity`.
- Модели: `Assets/Game/Art/Models` (из `Tools/Blender/make_models.py`).
- Шейдеры: `Assets/Game/Art/Shaders`. Изгиб мира — `CurvedWorld.hlsl` (подключён в `Particle`, `WeaponTrail`, `Silhouette`); `CurvedLit`/`CurvedUnlit` (`ColorsAction/Lit`, `/Unlit`) — копии URP Lit/Unlit с изгибом, генерируются `Tools/Shaders/make_curved_urp_shaders.py` (перезапустить после обновления URP), руками не править. Все материалы мира, игрока и оружия — на `ColorsAction/Lit`; в коде шейдер брать через `CurvedWorld.FindLit()`/`FindUnlit()`, не `Shader.Find("Universal Render Pipeline/Lit")`, иначе объект не изогнётся.

## Инструменты

- `Tools/ConfigEditor/ConfigEditor.html` — веб-редактор JSON-конфигов (враги — без радиуса агро, он в уровнях; таймлайны атак, круг цветов и множители урона, колесо оружия, инвентарь, цены апгрейдов, сундуки, ресурсы, мосты, урон от падения игрока, статус-эффекты и эффекты парирования; шкала выносливости врагов — в Бою и у врагов/оружия; серии ударов и удары по области у атак врагов).
- `Tools/LevelEditorWeb/index.html` — веб-редактор уровней (палитра — 6 цветов круга из Combat.json; на постаменте только оружие; у врага — радиус агро и оранжевый круг зоны; сундук: ресурс и количество, подпись на значке; разводной мост с направлением; дверь на ключ, ключ у врага, пунктир «враг → дверь», предупреждения о двери без ключа) (GitHub Pages, `.github/workflows/level-editor-pages.yml`).
- `Tools/Dev/CompileCheck.ps1` — быстрая проверка компиляции Unity-кода через dotnet, без редактора (`-Root <worktree>`).
- `Tools/Blender`, `Tools/Level` — генерация моделей и тестовых уровней.
- Плейтесты (только по запросу пользователя или перед пушем): Play Mode → ColorsAction/Debug/Run Prototype|Crate|Bridge Playtest. Результат читать из файла, а не из лога Unity: `Logs/playtest_result.txt` (прототип), `Logs/crate_playtest_result.txt`, `Logs/bridge_playtest_result.txt`: первая строка — итог, ниже только упавшие проверки. `RUNNING` — прогон ещё идёт, `ABORTED` — вышли из Play Mode раньше конца.
- Тесты логики: `dotnet/tests/ColorsAction.Tests`. Работа с редактором — через Unity CLI (`unity status / command / test / recompile`), не через MCP.
