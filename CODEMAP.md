# Карта кода ColorsAction

Сначала смотреть сюда, потом искать по коду. При изменении структуры (новые папки, системы, перенос файлов) — обновить карту.

## Сборки

| Сборка | Папка | Что внутри |
|---|---|---|
| `GameCore` (+`.Newtonsoft`) | `Packages/com.template.gamecore` | Шаблонное ядро без движка: DI, конфиги, события, FSM, тики, реактивный UI. Не трогать без нужды. |
| `GameCore.Unity` | `Packages/com.template.gamecore.unity` | Мост ядра к Unity: `GameHostBehaviour`, источники конфигов, логгер. |
| `ColorsAction.Game` | `Assets/Game/Logic` | Логика игры **без UnityEngine** (`noEngineReferences`). Тестируется `dotnet test dotnet/ColorsAction.sln`. |
| `ColorsAction.Unity` | `Assets/Game/Scripts` (кроме `Editor/`) | Всё, что живёт в сцене: игрок, бой, враги, уровень, UI. |
| `ColorsAction.Unity.Editor` | `Assets/Game/Scripts/Editor` | Сборщик сцены, плейтест, импорт моделей. |

## Логика (`Assets/Game/Logic`)

- `ColorsActionInstaller.cs` — регистрация сервисов в DI. `LaunchOptions.cs` — параметры запуска (уровень, стартовое оружие с апгрейдом, `FullWeaponUpgrades` — всё оружие с полной прокачкой через `GameSession.UpgradeAllWeapons`, по умолчанию выкл., опыт) и `LevelKeys` (ключ `VoxelLevels/…` — воксельная карта). `GameSession.cs` — состояние игры: инвентарь, выносливость, здоровье, опыт (он же «деньги» прокачки), открытые срезки, `CompletedHints`, `BrokenCrates` (разбитые ящики), `OpenedChests` (открытые сундуки), `OpenedBridges` (опущенные разводные мосты), `OpenedKeyDoors` (открытые двери на ключ), `DroppedKeys` (ключи, уже выпавшие из врагов), `LastBonfire`, `Upgrades`, схема управления; `GiveResources` (ресурсы в инвентарь, событие `ResourcesGained`); ключи — `PickUpKey(doorId)`, `HasKey`, `TryOpenKeyDoor` (ключ тратится).
- `Configs/` — классы JSON-конфигов: `Configs.cs` (Combat + `PoiseConfig` (Combat.json `poise`: сколько шкалы врага дают удар и парирование, спад); множители шкалы `ItemConfig.Poise`, `AttackStepConfig.Poise`, `PlungeConfig.Poise`, `ShieldConfig.BashPoise`; Game, Player + выносливость/здоровье (`PlayerHealthConfig`: максимум, прирост за уровень `MaxAt`, i-frames, мигание `BlinkHidden`)/деформация, Camera, Colors, Items + `AttackStepConfig` комбо с `fxFrom/fxTo`, `upgrade`, `hop`, `chargeable` (общий заряд оружия `ItemConfig.Charge`, `ChargeFor`), Combat, Inventory), `DodgeConfig.cs` (серия отскоков), `WeaponMoveConfigs.cs` (`ChargeConfig`, `FinisherConfig`, `PlungeConfig`), `UpgradeConfigs.cs` (Upgrades.json: цены апгрейдов — опыт + ресурс оружия `resource`/`resources`), `EnemyTypes.cs` (`ColorOf` — цвет врага: свой из карты или цвет типа; `Resolve` — старые id `тип_цвет` вроде `club_cube_orange` → тип `club_cube` + цвет), `ChestConfig.cs` (Chests.json: вид сундука, открытие, полёт ресурса), `EnemyConfigs.cs` (тип врага; `color` — только цвет типа по умолчанию, цвет каждого поставленного врага — `LevelEnemy.Color`/`LevelObject.Color` в карте; объём шкалы выносливости `poise`, `elite`, стойкость `hyperArmor`, `deflectDuration`; атака — движения `Sweep/Overhead/Slam/DiagonalRight/DiagonalLeft`, удар по области `areaRadius/areaOffset`, неблокируемый удар `unblockable` (сквозь блок, только парирование; замах — `EnemyBrain.UnblockableWindup`, знак «!»), серия ударов `combo` (`Step`, `StrikeSpan`); радиуса агро тут нет — он у врага на карте `LevelEnemy.AggroRadius`/`LevelObject.AggroRadius`, по умолчанию `LevelEnemy.DefaultAggroRadius`; `movement` — профиль из Movement.json для проверки достижимости), `CrateConfig.cs` (Crates.json: HP ящиков, `breakableBy`, вид), `BridgeConfig.cs` (Bridges.json: прочность цепи, `breakableBy` — дробовик, вид, падение створки), `StatusEffectsConfig.cs` (StatusEffects.json, ключ `StatusEffectsConfig.Key`: эффекты по id — вид `kind`, длительность, сила `value`, складывание `stacking`, подсветка `tint`; `onParry` — что враг получает при парировании кроме оглушения), `WaterConfig.cs` (Water.json, ключ `WaterConfig.Key`: вода вокруг уровня — высота над дном, «утонул», сетка, цвета, волны), `LevelConfig.cs` (+ `bonfires`, `keyDoors` (`LevelKeyDoor`), ключ у врага `LevelEnemy.Key` = id двери, `crates`, `chests` (ресурс и количество), `bridges`, подсказки с `target`).
- `Combat/` — `DamageRules` (урон × множитель цвета, `HitResult.Effect` — слабый/сильный/антипод), `ColorWheel` (круг 6 цветов из Combat.json `colorWheel`, расстояние по кругу → `colorDistanceMultipliers`), `Health`/`PlayerVitals`, `Stamina` (+ `Refund` — удачное парирование выносливость не тратит), `Poise` (шкала выносливости врага: `Add` → заполнилась `Broken`, спад после паузы, `HitAmount` — вклад удара), `EnemyBrain` (решения врага; свой `AggroRadius`, `LoseRadius` не меньше него; `Tick(..., playerReachable)` — недостижимого игрока спокойный враг не замечает; `Poise`: `OnDamaged(poise)` и `Parry` копят шкалу, полная — ошеломление (`Staggering`), парирование без полной шкалы лишь поглощает удар (`ParryStunned` = false, `Parried` на `DeflectDuration`); серии ударов `RootAttack`/`ComboIndex`; стойкость `HyperArmor`), `CombatDirector` (очередь врагов на атаку), `LockOnRules` (+ `Nearest` — передача фокуса), `Shotgun` (`ShotParams` — параметры залпа, `ShotPattern`, `PelletVolley`, `GunTrigger`), `DodgeCombo` (серия отскоков), `AttackCharge` (общий заряд удержанием: вспышка на пике, окно и спад множителя), `ComboFinisher` + `ComboSteps` (отложенный добивающий, удары за апгрейдами), `PlungeAttack` (удар в прыжке без потери инерции, удар при приземлении), `BlockRules` (блок за выносливость: щит гасит весь удар, дробовик — долю `GunBlockConfig.Absorb`; пробитый блок), `ShieldBash` (удар щитом; щит меча — `ItemConfig.Offhand`, его ступени прокачки — у меча: `ShieldConfig.BashUpgrade` и др.), `BreakableState` (`Breakable.cs`: здоровье разрушаемого, ломается только оружием из списка).
- `Status/` — статус-эффекты для врага и игрока: `StatusEffects` (контроллер носителя: `Apply(id, duration)`, `Remove`, `Clear`, `Tick`, события, сумма влияния `Modifiers` — `IsStunned`, `DamageTakenMultiplier`, `DamageDealtMultiplier`), `StatusEffect` (база: время, стаки, хуки `OnApplied/OnTick/OnRemoved/Modify`; `StatusModifiers`, `IStatusTarget`), `StatusEffectKinds` (реестр видов `kind` → класс: `StunEffect`, `DamageTakenEffect`, `DamageDealtEffect`; новый вид — класс + `Register`), `HealthStatusTarget` (урон эффектов в `Health`). Враг: `EnemyBrain.Status` (оглушение → состояние `Stunned`; парирование — стан на `ParriedDuration` + `ApplyParryEffects` в момент удара о щит). Игрок: `GameSession.PlayerStatus` (тикает TickScheduler; уязвимость — в `PlayerVitals.TryHit`, оглушение — `PlayerController.HasControl`).
- `Inventory/` — `PlayerInventory` (рук нет: оружие — на колесе `Weapons`, в руках `Active`, смена `SetActive`, `WeaponOfColor`; в сетке оружие не лежит; сетка и быстрые слоты 1–4 — расходники и ресурсы; `Hand` — только сторона сокета модели; `Item.Charges` — заряды расходников; стопки ресурсов `Item.Count`/`ItemConfig.MaxStack`: `CountOf`, `TryAddCount`, `TryConsume`, слияние перетаскиванием; ключ — `ItemKind.Key`, `Item.KeyFor` = id двери, `FindKey`), `ItemDatabase`, `HealItems` (лечилка: использование, восполнение у костра; подобранная фляга сразу встаёт в быстрый слот 1 — D-pad вверх, если он пуст; `GameSession.UseQuickItem`/`RefillConsumables`, событие `QuickItemUsed`).
- `Progression/` — `WeaponUpgrades` (уровни апгрейдов 0..3, `Has(itemId, tier)`; отладка `debugWeaponUpgrades` в Game.json — по умолчанию пусто, оружие с базы), `WeaponUpgradeShop` (покупка за опыт + ресурс оружия из инвентаря, `Missing` — чего не хватает), `Bonfire` (события отдыха/респауна).
- `Level/` — воксельная модель (`VoxelLevel`, `VoxelLevelData` (формат `CurrentFormat` = 2; файлы формата 1 — мост с клеткой «ближний край» — переводятся при чтении), `VoxelTypes`), `VoxelPlayLayout` (объекты воксельной карты → списки `LevelConfig` с высотой опоры `Y` для игры), `CrateStackShape` (стопка ящиков 2×1×N: клетки по yaw, объект `LevelObjectKind.CrateStack`), предмет на земле (не оружие, например фляга) — `LevelObjectKind.Item` (в игре как постамент оружия → `LevelConfig.Items`), сундук — `LevelObjectKind.Chest` (`Item` — ресурс, `Count` — количество), `DrawBridgeShape` (разводной мост 8×3, поднятая створка 4 в высоту; размеры — только константы тут, веб-редактор и модель берут их отсюда / `BRIDGE_*` в веб-редакторе: клетки по yaw, стена поднятой створки, объект `LevelObjectKind.DrawBridge`; клетка объекта — якорь на берегу сразу за дальним краем, высота настила — опора якоря, `Origin`/`AnchorOf` — начало моста ↔ якорь; в `LevelConfig.Bridges` игре уходит начало), двери на ключ — `LevelObjectKind.KeyDoor`, ключ — у врага `LevelObject.Key`; `KeyDoorRules` (предупреждения расстановки, те же в веб-редакторе, `Holders`, `AssignHolder`), правки и история (`LevelEditing`, `MarkupCommand.PutObjects` — несколько объектов одной отменой), `SurfaceSmoothing`, `ShortcutDoorRules` (+ `NearestPoint` — точка взаимодействия на широкой двери; `ShortcutDoorGroups` — двери-срезки вплотную в линию (одна сторона, этаж, высота) собираются в одну широкую `ShortcutDoorGroup`, формат карты не меняется), `HintTargets` (подсказки гаснут после подбора/двери), `LevelEdgeWalls` (невидимые стены по краю карты и высота смерти от падения), `WaterLayout` (вода: поверхность над дном, прямоугольник плоскости, высота «утонул» — поднимает высоту смерти), `Navigation/` (граф `NavGraph` и A* `PathFinder` (+ `FindOrClosest` — путь к ближайшему месту, если цель недостижима); `EnemyNavigator` — ведёт врага по пути A* к цели: высота (ступени, прыжки, спрыгивания по профилю Movement.json), прямые участки схлопываются, пересчёт при смене клетки цели/изменении мира/сходе с пути, `Stay` — ждать у края, `CanMove` — защита от шага с обрыва; `EnemyReach` — `FindPath`, `CanStep`, дойдёт ли враг до игрока: граф с настилом мостов (под дальней створкой — только когда мост опущен), закрытые двери (срезки и на ключ)/ящики/поднятые мосты — стены, кэш до изменения мира).
- `Animation/` — процедурная анимация кубов (игрок и враги), без движка, числа — `Configs/Animations.json` (`CubeAnimationConfig`, ключ `CubeAnimationConfig.Key`; словарь по id: `player`, `enemy`, запись с id типа врага заменяет `enemy` целиком; `Resolve`): `StepCycle` (цикл шагов по времени: частота `walkStepRate`/`runStepRate`, покачивание `Sway`, сжатие на шаге и вытягивание между шагами `Squash`, плавное появление/затухание), `CubeIdleAnimator` (покой: дыхание `BreathSquash` (`BreathWave`), моргание `Blink` (`BlinkCurve`), осмотр по сторонам игрока (`LookAround`: глаза `EyeX/EyeY` ведут, скручивание `Twist` догоняет), перебрасывание оружия врага из руки в руку (`Inspect`: `InspectProgress`/`InspectWeight`, `Toss` → `WeaponToss` — сторона, дуга, переворот, приседание при ловле; `InspectLift`; `Squash`); `Tick(dt, standing, action)` — любое действие прерывает: `Interrupt`, `CancelTime`; отладка `TriggerSpecial`/`TriggerBlink`), `CubeShape` (сжатие с сохранением объёма: `HeightScale`/`WidthScale`, та же формула в `CubeDeformer`).
- `Localization/` — тексты игры: `Strings` (строки языка из `Configs/Localization/<язык>.json` (`LocalizationConfig`: `strings` — ключ → текст, `controls` — подписи кнопок по пути Input System, для семейства геймпадов — с префиксом `ps:`), запасной язык `fallback`, нет ключа — сам ключ; регистрируется в DI), `LocText` (ключ + аргументы: так подписи отдают игровые объекты, например `IInteractable.Prompt`), `PromptText` (разметка: `{0}` — аргументы, `{action:id}` — кнопка действия под текущее устройство, `{{`/`}}` — скобки; `Parse` → куски текст/кнопка, `Plain` — «[F] взять»). Свой лёгкий JSON вместо Unity Localization: логика без движка, правки в JSON, тесты `LocalizationTests` (все ключи из кода и действия подсказок карт есть в ru.json).
- `States/States.cs` — FSM: Boot → Play ↔ Inventory / Bonfire. `UI/` — `InventoryScreenViewModel` (сетка + крестовина 1–4 `CrossLayout`, подпись оружия в руках `WeaponCaption`), `BonfireScreenViewModel`.

## Unity (`Assets/Game/Scripts`)

- `Core/` — `GameBootstrap` (точка входа сцены, хост ядра, создаёт HUD/колесо оружия/инвентарь/EventSystem из префабов и `LockOnOutline`, регистрирует `LaunchOptions`), `LaunchOptionsStore` (UserSettings/ColorsActionLaunch.json), `GameInput` (действия клавиатура/геймпад по GDD: TAB/Y — колесо `GameAction.Wheel`, I/Select — инвентарь (схемы А со свободной камерой больше нет: всегда 4 угла, `CameraScheme.FreeOrbit` остался только для автотестов); `PreviewStick` — правый стик в интерфейсе; `UsingGamepad`/`DeviceChanged` — последнее устройство, `GamepadFamily` — xbox/ps, `ActionsFor(id)` — действия за id подсказки (`attack`, `cameraTurn`, `items`…), `ControlPaths` — пути кнопок из привязок), `InputGlyphs` (кнопка действия под устройство: подпись из `controls` файла языка или имя Input System, иконка-спрайт `Resources/UI/InputGlyphs/<keyboard|mouse|xbox|ps>/<кнопка>` если есть, форма и цвет кнопки геймпада; `Label` — подпись строкой), `Palette`, `ComponentPool` (пулинг), `GlowMaterials` (копии материалов с `_EMISSION` для белой вспышки неуязвимости), `GameTimeScale` (единственный владелец `Time.timeScale`: замедление колеса + фриз-кадры удара).
- `Player/` — `PlayerController` (ходьба, бег, прыжок, серия отскоков, хуки удара в прыжке), `BoxMotor` (кинематика бокса), `CubeDeformer` (деформация куба; `Width` — ширина/глубина тела относительно меша 1×1: игрок `PlayerConfig.BodyWidth` 0.8; позы рук заданы для куба 1×1 и сжимаются вместе с ним; враги остаются кубами размера `EnemyConfig.Size`; пружины `SquashTarget/BendTarget/LeanTarget/TwistTarget/PitchTarget/DirSquashTarget` — отклик на удары, прыжки, перекаты; прямые добавки без пружин `DirectSquash`/`DirectBend` — шаги и дыхание; `TwistOffset`/`PitchOffset` — добавки к целям пружин (осмотр, перебрасывание оружия), удары их не затирают; глаза — вершины сабмеша 1: `EyeOffset` (взгляд), `EyeBlink`/`EyeClosedScale` (моргание)), анимации шагов и покоя игрока — `PlayerController.UpdateDeformation`/`UpdateIdle` (`Idle`, `Steps`, `InterruptIdle`; покой прерывают ввод, поворот, фиксация, колесо оружия, удар по игроку, занятые руки — `PlayerCombat.Calm`), `PlayerDamageReceiver` (урон, блок, i-frames с белым свечением тела и оружия, смерть/респаун, смерть при падении ниже `PlayerController.KillHeight` (задаёт `LevelBuilder`), урон от падения с высоты по ступеням `PlayerConfig.FallDamage`, поднятым на высоту прыжка — `PlayerConfig.FallDamageFraction`, быстрые слоты 1–4 — лечилка), `PlayerLockOn` (фиксация цели: враги, манекены, цепи мостов), `LockOnOutline` (белый контур силуэта цели фиксации: на каждый MeshRenderer цели — дочерние рендереры с материалами Resources/Materials/LockOutlineMark (стенсил) и LockOutlineHull (раздутая оболочка, шейдеры `OutlineMark`/`OutlineHull`); сглаженные нормали в TEXCOORD3; создаёт `GameBootstrap`), `AimMarker`.
