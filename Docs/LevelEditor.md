# Редактор уровней (GDD §15)

Открыть: меню **ColorsAction → Level Editor** (Ctrl+Shift+L). Работа идёт мышью в Scene View, окно служит панелью инструментов.
Лучше редактировать в пустой сцене (кнопка «Пустая сцена для редактирования»), чтобы превью не накладывалось на уровень прототипа.
Превью не сохраняется в сцену.

## Инструменты

| Инструмент | Что делает |
|---|---|
| Рисовать | Ставит блок на высоте H (от низа активного этажа). Форма: куб, полублок, ступенька 0.25, слоп, верх слопа, крутой слоп, декор. Режим «Столбец» заполняет от пола этажа до H. Кисть 1–9 клеток. |
| Стереть | Убирает блоки только на высоте H, ниже и выше остаются. |
| Красить | Меняет цвет стоящих блоков (форма не меняется). Цвета из `Configs/Colors.json`, «Мир» — цвет по умолчанию. |
| Объекты | Барьеры (стена, ящик, мембрана, решётка; цвет и высота), оружие на постаменте, костёр, спавн врага, NPC, подсказка, точка появления. |
| Точки | Точки взаимодействия: спуск на щите, лифт, якорь крюка, кольцо кистеня, рычаг, дверь-срезка, переход между этажами. Первый щелчок ставит точку A, второй — цель: пустая клетка создаёт точку B, щелчок по точке или объекту связывает с ним. Условие (предмет, открытый барьер) задаётся у выбранной точки. |
| Выбор | Выбрать объект или точку и править их в окне. |

Клавиши в Scene View: Shift+колесо — H, PgUp/PgDn — этаж, R — поворот слопа, Ctrl+ЛКМ — пипетка, Ctrl+Z/Ctrl+Y — отмена/повтор
(мазок целиком — одно действие, работает через Undo Unity), Delete — удалить выбранное, Esc — снять выбор.

Этажи: активный этаж обычный, верхние полупрозрачные или скрытые, нижние затемнены. У этажа есть низ (Y), H считается от него.

## Плавные перепады

Перепады до 0.3 (ступенька 0.25 рядом с полом) не рисуются ступенькой: верх нижней клетки наклоняется к соседу, получается слоп.
Правило общее с тестовым уровнем прототипа (`SurfaceSmoothing` в логике, у карты высот — `LevelConfig.TopCorners`):
каждый угол верха поднимается до самого высокого соседнего верха (стороны и диагональ), если тот выше не больше чем на 0.3.
Перепады больше (полублок 0.5, куб) остаются стенками. Карта пути берёт высоты с наклона.

## Карта пути

Своя воксельная карта с A* (`Packages/com.colorsaction.game/Runtime/Level/Navigation`), не NavMesh.
Узел — верх блока со свободным местом над ним. Связи: шаг (перепад до `stepHeight`, слопы), прыжок (до `jumpHeight`),
спрыгивание (до `maxDrop`), диагонали без срезания углов, особые связи из точек взаимодействия. Закрытый барьер закрывает клетку,
условия точек проверяются по состоянию мира (`INavContext`).
Профили перемещения — `Configs/Movement.json`: игрок, обычный враг (не прыгает), «Глыба» (2 клетки ростом, не прыгает).
Наложение: зелёные клетки — проходимы для профиля, синие стрелки — прыжки, оранжевые — спрыгивания, сиреневые — особые связи.
Карта пересобирается при сохранении и по кнопке «Пересобрать».

## Файлы

- Уровни: `Assets/StreamingAssets/Configs/VoxelLevels/*.json` (формат описан в `VoxelLevelData`). `VoxelLevels/Test` — импорт
  карты высот `Levels/Test` плюс пример башни со спуском на щите и красным барьером.
- Логика без движка: `Packages/com.colorsaction.game/Runtime/Level` (модель, история правок, кисть, импорт, карта пути), тесты —
  `dotnet/tests/ColorsAction.Tests/LevelEditorTests.cs`.
- Меши: `Assets/Game/Scripts/Level/Voxel` (`VoxelLevelView` — куски 16×16 по этажам, сабмеш на цвет, опционально коллайдеры).
- Окно: `Assets/Game/Scripts/Editor/LevelEditor` (своя сборка `ColorsAction.LevelEditor`).
